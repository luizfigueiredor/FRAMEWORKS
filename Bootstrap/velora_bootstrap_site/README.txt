# VELORA — site Bootstrap

## Arquivos
- `index.html`: estrutura e conteúdo da página.
- `style.css`: cores, fontes, espaçamentos e responsividade.
- `script.js`: ano automático do rodapé e demonstração do formulário.

## Como abrir
1. Extraia a pasta do ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador (ou use a extensão Live Server).
4. Mantenha conexão com a internet para carregar Bootstrap, fontes e imagens externas.

## Personalização
- Troque as imagens pelas fotos oficiais da VELORA.
- Altere textos e links no `index.html`.
- Altere as cores e tamanhos no `style.css`, principalmente as variáveis dentro de `:root`.
- O formulário de newsletter é apenas demonstrativo: para receber e-mails de verdade, será necessário conectar um backend ou serviço de formulários.
- Links de redes sociais e sacola estão como exemplos e precisam ser configurados.

O layout foi inspirado no exemplo Carousel do Bootstrap 5.3 e usa classes Bootstrap para navegação, grade, botões e carrossel.
